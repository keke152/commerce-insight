# Commerce Insight 使用手册

一个使用 Python 实现的本地电商订单分析项目。把客户授权导出的跨平台订单导入后，系统会统一展示订单、自动识别商品品类，并根据客户历史购买节奏计算近期复购机会。

> 当前数据均为本地生成的虚构演示数据。项目不登录或抓取任何真实平台；真实接入应由客户授权，并通过平台官方开放 API 或客户提供的合规数据导出文件完成。

## 快速启动（Windows）

1. 安装 Python 3.10 或更高版本。
2. 双击 `start.bat`，首次运行会建立虚拟环境并安装依赖。
3. 浏览器打开 `http://127.0.0.1:8000`。
4. 点击“导入订单”，选择 `sample_orders.csv`，可看到导入、分类、去重和复购预测流程。

演示数据会在首次启动时自动生成；可随时导入样例 CSV。订单号在“平台 + 订单号”范围内去重。

## 演示流程（约 3 分钟）

1. 从经营总览介绍跨平台订单数、近 30 天销售额、成交客户和复购机会。
2. 展示“订单品类分布”，说明每笔订单都会保存品类、置信度和分类理由。
3. 在最近订单中按商品、客户或订单号搜索，也可按品类筛选。
4. 导入 `sample_orders.csv`，观察新订单进入系统后总览、订单表和复购机会清单自动刷新。重复导入时已存在的订单会跳过。
5. 打开“复购机会清单”，解释客户购买次数、平均周期、距离上次购买天数和复购可能性。
6. 展示“数据接入”部分，说明目前是授权 CSV 演示入口，线上需要接平台官方 API、加密凭据、增量同步和审计日志。

## 数据格式

CSV 必须含有 `order_id`、`customer_id`、`product_name`、`amount`、`ordered_at` 列。可选列为 `platform`、`quantity`。日期格式为 `YYYY-MM-DD`；金额为数字。

系统只接受 CSV，不含网站登录、验证码处理或绕过平台访问限制的代码。生产接入应先确认数据处理授权范围、平台 API 条款、客户告知与删除机制，并仅保存实现业务所需的数据字段。

## 分类和复购逻辑

- **品类分类**：使用可解释的关键词基线，对商品名称做多品类词典匹配，返回品类、置信度和命中词。无法识别的订单落入“其他”，进入人工复核队列的后续扩展范围。
- **复购判断**：对每个客户的每个品类，按订单日期计算平均购买间隔；当距上次购买达到该品类周期的 65% 后进入候选清单。得分随周期临近程度和购买次数上升。
- **业务边界**：分数是可解释的排序分值，不是经过校准的真实概率，也不能替代客户触达决策。上线后应使用时间切分回测、品类级误差指标和运营反馈校准模型。
- **模型升级**：保留分类与推荐服务边界，后续可把规则基线替换为商品分类模型和复购生存分析/排序模型；提供置信度阈值、人审与反馈回流。

## 数据库

默认使用 SQLite，运行即创建 `demo.db`。生产环境可在启动前配置 `DATABASE_URL` 切换到 MySQL：

```powershell
$env:DATABASE_URL = "mysql+pymysql://app_user:password@127.0.0.1:3306/commerce_copilot?charset=utf8mb4"
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

生产部署还需要迁移脚本、数据库备份与恢复策略、鉴权、租户隔离、字段加密、密钥托管、访问审计、速率限制和异常监控。此演示版为了便于现场启动，未实现这些生产控制。

## 接口速览

- `GET /api/health`：服务状态与数据库类型
- `GET /api/summary`：经营指标与品类分布
- `GET /api/orders?q=&category=&platform=`：订单检索
- `GET /api/recommendations`：复购机会及解释字段
- `POST /api/import/csv`：导入已授权 CSV
