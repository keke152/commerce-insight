# 后续计划

## 优先：真实授权数据接入

- 平台官方开放 API 连接器、授权令牌存储、过期刷新与撤销。
- 增量游标、分页、超时、限流、幂等及同步任务记录。
- 多商品订单、退款取消事件、商家统一客户ID映射。

## 服务化

- 登录、租户数据隔离、用户级操作审计。
- MySQL端到端验证、显式数据库迁移和备份恢复。
- 异步导入任务、数据库侧分页聚合及大数据量性能测试。

## 模型和运营验证

- 真实授权商品标注、长尾测试、类别混淆矩阵和分值校准。
- 对低分商品探索大模型结构化分类，记录成本、延迟、失败降级与隐私边界。
- 复购时间回测、运营反馈、对照实验，验证实际触达效果。

以上均为计划，当前版本未实现；不使用未经测量的线上效果或业务增长指标。
