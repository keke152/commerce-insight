## 页面与快捷操作

| 地址片段 | 页面 |
| --- | --- |
| #overview | 经营总览 |
| #orders | 订单与分类 |
| #customers-list | 复购机会 |
| #segments | 客户分层 |
| #model | 模型实验台 |
| #integrations | 数据接入 |

页面可刷新、复制地址，也支持浏览器前进后退。顶部搜索回车后切换到订单页，并清空分类、平台和待复核条件再搜索。输入框之外按 `/` 可聚焦搜索；手机上打开订单页搜索。

手机通过顶部菜单打开侧栏，点击页面、遮罩或按Escape关闭。打开时限制键盘焦点在导航内；关闭并选页后焦点转入内容标题。遵循系统减少动画设置。

## 销售趋势口径

`GET /api/trends?days=30` 返回包含今天及前29天的每日金额和订单数，缺少订单的日期补零；支持7至90天，界面提供7/30天切换。仅汇总订单金额，未扣退款或经营成本。30天总额与总览的 `revenue_30d` 一致。

首页横幅内的线条为装饰图，已标记为辅助技术忽略；“销售趋势”面板才是实际数据图。
